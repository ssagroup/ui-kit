# Radio

A single radio button with a label. Radios are almost always used inside
`RadioGroup`, which owns the selected value and wires up every child — see
its page for layouts, controlled groups and form use. Use a standalone Radio
only when you manage `checked` for each button yourself.

## Default Usage

<Description of={RadioStories.Default} />

```tsx
import { useState } from 'react';
import { Radio, RadioGroup } from '@ssa-ui-kit/core';

const Billing = () => {
  const [plan, setPlan] = useState<string | number>('monthly');
  return (
    <RadioGroup name="billing" value={plan} onChange={setPlan}>
      <Radio id="billing-monthly" value="monthly" text="Monthly billing" />
      <Radio id="billing-yearly" value="yearly" text="Yearly billing" />
    </RadioGroup>
  );
};
```

## States

<Description of={RadioStories.States} />

| `color`               | Resting / checked | Hover            | Disabled          |
| --------------------- | ----------------- | ---------------- | ----------------- |
| `primary` _(default)_ | `primary.main`    | `primary.dark`   | `greyFocused40`   |
| `success`             | `success.main`    | `success.dark`   | `greyFocused40`   |
| `custom`              | `colors.default`  | `colors.hovered` | `colors.disabled` |

Set `color` on `RadioGroup` to apply it to every child; a `color` on a single
Radio wins over the group's.

## Keyboard and Accessibility

Radio is a native `<input type="radio">` inside a `<label>`.

- **`text` is the accessible name.** Without it the radio has no name.
- Radios that share a `name` form one Tab stop; the arrow keys move between
  them and select the one they land on. RadioGroup sets the shared `name`.
- The input is visually hidden and no focus ring is drawn yet, so keyboard
  focus is not visible.
- `disabled` removes the radio from keyboard navigation.
