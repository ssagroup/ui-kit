# FiltersMultiSelect

A search field for building a filter set: each option can be **included** or
**excluded**, and `group` options (saved sets, say) are simply selected. The
picked filters show as coloured badges inside the field. For a plain
multi-select use `MultipleDropdown` or `Typeahead`.

## Default Usage

<Description of={FiltersMultiSelectStories.Default} />

```tsx
import {
  FiltersMultiSelect,
  FiltersMultiSelectOptions,
  FiltersMultiSelectOption,
  useFilterMultiSelect,
  type Filter,
} from '@ssa-ui-kit/core';

const filters: Filter[] = [
  { id: 'active', label: 'Active users' },
  { id: 'churned', label: 'Churned' },
  { id: 'saved-vip', label: 'Saved: VIP customers', group: true },
];

const store = useFilterMultiSelect({
  onChange: (selected) => console.log(selected),
});

<FiltersMultiSelect store={store} label="User filters">
  <FiltersMultiSelectOptions>
    {filters
      .filter((filter) =>
        filter.label.toLowerCase().includes(store.search.toLowerCase()),
      )
      .map((filter) => (
        <FiltersMultiSelectOption key={filter.id} filter={filter}>
          {filter.label}
        </FiltersMultiSelectOption>
      ))}
  </FiltersMultiSelectOptions>
</FiltersMultiSelect>;
```

## Controlled Selection

<Description of={FiltersMultiSelectStories.Controlled} />

```tsx
import { useState } from 'react';
import { useFilterMultiSelect, type SelectedFilter } from '@ssa-ui-kit/core';

const [selected, setSelected] = useState<SelectedFilter[]>([
  { id: 'active', label: 'Active users', type: 'include' },
]);
const store = useFilterMultiSelect({
  selectedFilters: selected,
  onChange: setSelected,
});

// Render <FiltersMultiSelect store={store}> as in Default Usage
```

## The Store

`useFilterMultiSelect` holds the selection, the search text and the open
state; each can be controlled (`selectedFilters` / `search` / `open` with
`onChange` / `onSearchChange` / `onOpenChange`) or seeded
(`defaultSelectedFilters` / `defaultSearch` / `defaultOpen`).
`onDropdownOpen` and `onDropdownClose` report the list opening and closing.

| Member                        | Does                                                                        |
| ----------------------------- | --------------------------------------------------------------------------- |
| `selectedFilters`             | Current selection, `{ id, label, type }[]`                                  |
| `search`                      | Current search text — filter the options with it                            |
| `open`                        | Whether the list is open                                                    |
| `selectFilters(...filters)`   | Adds filters, or changes the `type` of ones already selected                |
| `unselectFilters(...filters)` | Removes entries — matched by reference, so pass ones from `selectedFilters` |
| `isSelected(id)`              | The selected entry for `id`, if any                                         |
| `setSearch(text)`             | Sets the search text                                                        |
| `toggleDropdown(open?)`       | Opens, closes or toggles the list                                           |

The component's own `selectedFilters` and `onChange` props drive a built-in
store and are ignored once you pass `store`.

## Keyboard and Accessibility

Focus stays in the search input while the list is open; the highlighted row
is announced through `aria-activedescendant`.

| Key                     | Action                                                                      |
| ----------------------- | --------------------------------------------------------------------------- |
| `ArrowDown` / `ArrowUp` | Open the list; move the highlight                                           |
| `Enter`                 | Cycle the highlighted row: none → include → exclude → none (groups: on/off) |
| `Escape`                | Close the list and leave the input                                          |
| `Tab`                   | Close the list and move focus on                                            |

`label` names the search input. With `searchable={false}` there is no input,
so the list can only be opened with the pointer (the badges' remove buttons
and the clear button stay reachable with `Tab`).
