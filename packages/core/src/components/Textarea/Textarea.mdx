# Textarea

A bare multi-line text field wired to react-hook-form through `register`. It
renders no label, helper text or counter — for a complete field use
`TextField multirow`; reach for Textarea when you lay out the label and
messages yourself.

## Default Usage

<Description of={TextareaStories.Default} />

```tsx
import { Textarea } from '@ssa-ui-kit/core';
import { useForm } from 'react-hook-form';

const MessageBox = () => {
  const { register } = useForm();
  return (
    <Textarea
      name="message"
      placeholder="Write a message"
      rows={4}
      register={register}
      validationSchema={{ required: 'Write a message first' }}
    />
  );
};
```

## Character Counter

<Description of={TextareaStories.CharacterCounter} />

```tsx
import { useState } from 'react';
import { FormHelperText, Textarea } from '@ssa-ui-kit/core';
import { useForm } from 'react-hook-form';

const Bio = () => {
  const { register } = useForm();
  const [count, setCount] = useState(0);
  return (
    <div>
      <Textarea
        name="bio"
        maxLength={200}
        register={register}
        setCountChar={(event) =>
          setCount((event.target as HTMLTextAreaElement).value.length)
        }
      />
      <FormHelperText>{count} / 200</FormHelperText>
    </div>
  );
};
```

## Keyboard and Accessibility

Textarea is a native `<textarea>`: it takes focus with Tab, Enter adds a new
line, and it has no keyboard handling of its own.

- **Label it.** Textarea renders no `<label>`. Point a `<label htmlFor>` or
  `Field.Label` at its `id` (`formElement-{name}` unless you pass `id`).
- `aria-describedby` passes through, for a label badge or your own helper
  text.
- `status="error"` only colours the border; it does not set `aria-invalid`.
- `readOnly` keeps the text focusable and selectable; `disabled` removes it
  from the tab order.
