# Textarea

## Default Usage

The Textarea component provides a multi-line text input area designed specifically for React Hook Form integration. It offers a clean, modern design with hover and focus states, and must be used within a form context with the register function:

```tsx
import { useForm } from 'react-hook-form';
import { Textarea } from '@ssa-ui-kit/core';

function BasicTextarea() {
  const {
    register,
    handleSubmit,
    formState: { errors },
  } = useForm();

  const onSubmit = (data: any) => {
    console.log('Form data:', data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <Textarea
        name="description"
        placeholder="Enter your description here..."
        register={register}
        validationSchema={{
          required: 'Description is required',
          minLength: { value: 10, message: 'Minimum 10 characters required' },
        }}
        rows={6}
      />
      <button type="submit">Submit</button>
    </form>
  );
}
```

## Features

### Basic Textarea

Simple textarea with placeholder and validation:

```tsx
function BasicTextareaExample() {
  const {
    register,
    formState: { errors },
  } = useForm();

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '16px' }}>
      <Textarea
        name="comments"
        placeholder="Enter your comments..."
        register={register}
        validationSchema={{
          required: 'Comments are required',
        }}
        rows={4}
      />

      <Textarea
        name="feedback"
        placeholder="Share your feedback with us..."
        register={register}
        validationSchema={{
          maxLength: { value: 500, message: 'Maximum 500 characters allowed' },
        }}
        rows={6}
        maxLength={500}
      />
    </div>
  );
}
```

### Label

`label` renders the kit `Label` above the textarea with the same 6px gap as `TextField`, so a
labelled Textarea lines up with the fields next to it. `required` adds a red `*` after the label and
sets `aria-required` on the textarea; `labelBadge` adds a status badge that describes it. Without
`label` nothing is rendered above the control.

```tsx
<Textarea
  name="summary"
  label="Summary"
  required
  labelBadge={{ text: 'mapped', color: 'primary' }}
  register={register}
  validationSchema={{ required: 'Summary is required' }}
/>
```

The `*` is decorative (`aria-hidden`), so the accessible name stays the label text. `required` does
not validate: keep the rule in `validationSchema`.

### Disabled and Read-Only States

Handle different interaction states:

```tsx
function TextareaStates() {
  const { register } = useForm({
    defaultValues: {
      disabled: 'This content cannot be edited',
      readonly: 'This content is read-only but can be selected and copied',
    },
  });

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '20px' }}>
      <Textarea
        name="disabled"
        label="Disabled Textarea"
        placeholder="This textarea is disabled"
        register={register}
        disabled={true}
        rows={4}
      />

      <Textarea
        name="readonly"
        label="Read-Only Textarea"
        placeholder="This textarea is read-only"
        register={register}
        readOnly={true}
        rows={4}
      />
    </div>
  );
}
```
