# Input

A single-line text field: a bordered `<input>` with status styling, optional
start / end elements and a helper row, wired to react-hook-form through
`register`. It renders no label.

| Need                                            | Use                                  |
| ----------------------------------------------- | ------------------------------------ |
| A labelled form field with helper / error text  | `TextField`                          |
| A label, control and messages laid out your way | `Field` with an `Input` inside       |
| Multi-line text                                 | `Textarea` (or `TextField multirow`) |
| A formatted number                              | `NumberField`                        |
| A search box with debounced search              | `SearchBox`                          |
| Just the field, labelled elsewhere              | `Input`                              |

## Default Usage

<Description of={InputStories.Default} />

```tsx
import { Input } from '@ssa-ui-kit/core';
import { useForm } from 'react-hook-form';

const EmailInput = () => {
  const { register } = useForm();
  return (
    <Input
      name="email"
      type="email"
      placeholder="Enter your email"
      register={register}
      inputProps={{ 'aria-label': 'Email' }}
    />
  );
};
```

## React Hook Form

<Description of={InputStories.ReactHookForm} />

```tsx
import { Button, Input } from '@ssa-ui-kit/core';
import { FieldError, useForm } from 'react-hook-form';

const ContactForm = () => {
  const {
    register,
    handleSubmit,
    formState: { errors },
  } = useForm();

  return (
    <form onSubmit={handleSubmit((data) => console.log(data.email))}>
      <Input
        name="email"
        type="email"
        placeholder="Email"
        register={register}
        validationSchema={{
          required: 'Email is required',
          pattern: { value: /^\S+@\S+\.\S+$/, message: 'Invalid email' },
        }}
        status={errors.email ? 'error' : 'basic'}
        errors={errors.email as FieldError}
        showHelperText
      />
      <Button type="submit" variant="primary" text="Submit" />
    </form>
  );
};
```

## Without React Hook Form

<Description of={InputStories.WithoutReactHookForm} />

```tsx
import { useState } from 'react';
import { Input } from '@ssa-ui-kit/core';

const Query = () => {
  const [value, setValue] = useState('');
  return (
    <Input
      name="query"
      placeholder="Type something"
      inputProps={{
        value,
        onChange: (event) => setValue(event.target.value),
        'aria-label': 'Query',
      }}
    />
  );
};
```

## Keyboard and Accessibility

Input is a native `<input>`: it takes focus with Tab and has no keyboard
handling of its own.

- **Label it.** Input renders no `<label>`. Use `TextField`, a `Field.Label`
  with `htmlFor="formElement-{name}"` (the input's default id), or
  `inputProps={{ 'aria-label': '…' }}`. `inputProps.id` replaces the default
  id.
- The helper row is `role="status"`, so its text is announced when it changes.
  It is not linked to the input with `aria-describedby`, and
  `status="error"` does not set `aria-invalid` — add them through `inputProps`
  if you need them.
- Start / end elements are not focusable unless they are controls themselves;
  give icon-only buttons an `aria-label`.
