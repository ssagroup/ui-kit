# RadioGroup

A single choice from a short set of options. RadioGroup owns the selected
value and wires up its `Radio` children. For a long list use `Dropdown`; inside
a react-hook-form form use `FormRadioGroup`.

## Default Usage

<Description of={RadioGroupStories.Default} />

```tsx
import { Radio, RadioGroup } from '@ssa-ui-kit/core';

const periods = [
  { value: 'monthly', label: 'Monthly' },
  { value: 'yearly', label: 'Yearly' },
];

const BillingPeriod = () => (
  <fieldset>
    <legend>Billing period</legend>
    <RadioGroup
      name="billing"
      defaultValue="monthly"
      onChange={(value) => console.log(value)}
      css={{ display: 'flex', gap: 24 }}>
      {periods.map(({ value, label }) => (
        <Radio key={value} id={`billing-${value}`} value={value} text={label} />
      ))}
    </RadioGroup>
  </fieldset>
);
```

## Controlled

<Description of={RadioGroupStories.Controlled} />

```tsx
import { useState } from 'react';
import { Radio, RadioGroup } from '@ssa-ui-kit/core';

const Size = () => {
  const [size, setSize] = useState<string | number | undefined>('medium');
  return (
    <RadioGroup name="size" value={size} onChange={setSize}>
      <Radio id="size-small" value="small" text="Small" />
      <Radio id="size-medium" value="medium" text="Medium" />
      <Radio id="size-large" value="large" text="Large" />
    </RadioGroup>
  );
};
```

## With react-hook-form

Use `FormRadioGroup`: it takes the same children plus `name` and `control`,
and writes the picked value into the form. Spreading `register()` onto each
`Radio` does not work — Radio forwards no `ref`, and the group replaces each
child's `onChange`.

## Keyboard and Accessibility

The radios are native `<input type="radio">` elements sharing the group's
`name`.

| Key        | Action                                                     |
| ---------- | ---------------------------------------------------------- |
| Tab        | Moves into the group (to the selected radio) and out again |
| Arrow keys | Move to the next or previous radio and select it           |
| Space      | Selects the focused radio                                  |

- **Name the group.** The wrapper has `role="radiogroup"` but no accessible
  name of its own — wrap it in a `<fieldset>` with a `<legend>`, as the
  stories do.
- `isRequired` sets `aria-required` on the group and `required` on every
  radio.
- Disabled radios are skipped by the arrow keys.
- There is no visible focus ring yet (see Radio).
