# MultipleDropdown

A select-only control for choosing several options from a list: a toggle
button that shows a label, the first selection and a `+N` badge, and a list
of `DropdownOption`s with a checkbox per row. For a single choice use
`Dropdown`; for a searchable list use `Typeahead`.

## Default Usage

<Description of={MultipleDropdownStories.Default} />

```tsx
import { useState } from 'react';
import { MultipleDropdown, DropdownOption } from '@ssa-ui-kit/core';

type Item = { value: number; label: string };

const items: Item[] = [
  { value: 1, label: 'Design' },
  { value: 2, label: 'Engineering' },
  { value: 3, label: 'Finance' },
];

const [selected, setSelected] = useState<Item[]>([items[0]]);

<MultipleDropdown
  label="Departments"
  selectedItems={selected}
  onChange={(value, isSelected) =>
    setSelected((prev) =>
      isSelected
        ? [...prev, ...items.filter((item) => item.value === value)]
        : prev.filter((item) => item.value !== value),
    )
  }>
  {items.map((item) => (
    <DropdownOption key={item.value} value={item.value} label={item.label} />
  ))}
</MultipleDropdown>;
```

## Groups

<Description of={MultipleDropdownStories.Groups} />

```tsx
import {
  MultipleDropdown,
  DropdownOption,
  DropdownOptionGroup,
} from '@ssa-ui-kit/core';

<MultipleDropdown
  label="Ingredients"
  selectedItems={[{ value: 'apple' }]}
  onChange={(value, isSelected) => console.log(value, isSelected)}>
  <DropdownOptionGroup label="Fruits">
    <DropdownOption value="apple" label="Apple" />
    <DropdownOption value="banana" label="Banana" />
  </DropdownOptionGroup>
  <DropdownOptionGroup label="Vegetables">
    <DropdownOption value="carrot" label="Carrot" />
  </DropdownOptionGroup>
</MultipleDropdown>;
```

## Controlled Selection

<Description of={MultipleDropdownStories.Controlled} />

The `onChange` in [Default Usage](#default-usage) is the full pattern. To
change the selection from outside, set the state:

```tsx
// `items`, `selected` and `setSelected` as in Default Usage
<button onClick={() => setSelected(items)}>Select all</button>
<button onClick={() => setSelected([])}>Clear</button>
```

## Keyboard and Accessibility

The toggle is a select-only `combobox` that keeps focus while the list is open;
the highlighted option is announced through `aria-activedescendant`. The list
is a multi-selectable `listbox` in multi-select mode.

| Key                     | Action                                                                              |
| ----------------------- | ----------------------------------------------------------------------------------- |
| `ArrowDown` / `ArrowUp` | Open the list; move the highlight                                                   |
| `Home` / `End`          | Highlight the first / last option                                                   |
| `Enter` / `Space`       | Open the list; toggle the highlighted option (pick and close in single-select mode) |
| `Escape`                | Close the list                                                                      |
| `Tab`                   | Close the list and move focus on                                                    |

`fieldLabel` is wired to the toggle through `aria-labelledby`, and
`labelBadge` through `aria-describedby`. The inline `label` prefix is not an
accessible name, so give the field a `fieldLabel`.
