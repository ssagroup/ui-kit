# Drawer

## Default Usage

The Drawer component provides a slide-out panel that overlays or pushes content from any side of the screen. It's composed of multiple parts and uses a hook-based API for state management:

```tsx
import { Drawer, useDrawer, Button } from '@ssa-ui-kit/core';

function BasicDrawer() {
  const drawer = useDrawer({
    title: 'Settings',
    withCloseButton: true,
  });

  return (
    <>
      <Button {...drawer.interactions.getReferenceProps()}>
        {drawer.open ? 'Close' : 'Open'} Drawer
      </Button>

      <Drawer.Root store={drawer}>
        <Drawer.Portal>
          <Drawer.Overlay>
            <Drawer.Content css={{ padding: '24px', maxWidth: '400px' }}>
              <h3>Drawer Content</h3>
              <p>
                This is the drawer content area where you can place any
                components.
              </p>
            </Drawer.Content>
          </Drawer.Overlay>
        </Drawer.Portal>
      </Drawer.Root>
    </>
  );
}
```

## Features

### Positioning

Control which side of the screen the drawer slides from:

```tsx
// Left side (default)
const leftDrawer = useDrawer({ position: 'left' });

// Right side
const rightDrawer = useDrawer({ position: 'right' });

// Top side
const topDrawer = useDrawer({ position: 'top' });

// Bottom side
const bottomDrawer = useDrawer({ position: 'bottom' });
```

### Portal vs Container Rendering

Render the drawer in a portal (for overlays) or within a container:

```tsx
// Portal rendering (overlay mode)
<Drawer.Root store={drawer}>
  <Drawer.Portal>
    <Drawer.Overlay>
      <Drawer.Content>
        Content overlays the page
      </Drawer.Content>
    </Drawer.Overlay>
  </Drawer.Portal>
</Drawer.Root>

// Container rendering (inline mode)
<div style={{ position: 'relative', overflow: 'hidden' }}>
  <Drawer.Root store={drawer}>
    <Drawer.Content>
      Content pushes other content
    </Drawer.Content>
  </Drawer.Root>
</div>
```

### Header with Title and Close Button

Compose the header from its parts:

```tsx
const drawer = useDrawer();

<Drawer.Content>
  <Drawer.Header>
    <Drawer.Title>Custom Title</Drawer.Title>
    <Drawer.CloseButton />
  </Drawer.Header>
  <div>Main content here</div>
</Drawer.Content>;
```

> **`title` and `withCloseButton` are deprecated.** Passing either makes
> `Drawer.Content` build a header for you, which predates these parts and
> cannot hold anything besides a title and a close button — a drawer needing a
> save button or a search field has to abandon it. They keep working and warn
> in development; they are removed in the next major release.

### Header Actions

`Drawer.Actions` is the header's right-hand control group — 20px apart,
vertically centred. It lays the controls out and nothing more, so each one is
an ordinary kit component whose label, variant and disabled state stay yours.

```tsx
<Drawer.Header>
  <Drawer.Title>Filters</Drawer.Title>
  <Drawer.Actions>
    <Button variant="primary" text="Save" onClick={handleSave} />
    <Drawer.CloseButton />
  </Drawer.Actions>
</Drawer.Header>
```

Swap the button for a search field and the same group carries it:

```tsx
<Drawer.Actions>
  <Input name="search" placeholder="Search" onChange={handleSearch} />
  <Drawer.CloseButton />
</Drawer.Actions>
```

> **Compose the header yourself, or let the store build it — not both.**
> Passing `title`/`withCloseButton` to `useDrawer` makes `Drawer.Content`
> render its own header. Writing your own means leaving both unset, or the
> drawer draws two.

### Footer Actions

`Drawer.Footer` is a sticky bar across the bottom of the panel, above a
full-width divider. It stays put whether the body is short or scrolling.
Place it as the last child of `Drawer.Content`.

```tsx
<Drawer.Content>
  <Drawer.Header>
    <Drawer.Title>Filters</Drawer.Title>
    <Drawer.CloseButton />
  </Drawer.Header>
  {fields}
  <Drawer.Footer>
    <Button variant="custom" text="Clear" onClick={handleClear} />
    <Button variant="primary" text="View leads" onClick={handleSubmit} />
  </Drawer.Footer>
</Drawer.Content>
```

### Panel Width

`left`/`right` drawers are 400px wide by default. `top`/`bottom` span the
overlay and ignore the option.

```tsx
const drawer = useDrawer({ position: 'right', width: 572 });
```

### The Toggle Glyph

`Drawer.CloseButton` picks its icon from `position`: the side drawers use
`panelLeft`/`panelRight`, which point at the edge the drawer is anchored to, so
the button reads as "collapse towards this side" rather than as a generic
arrow. `top`/`bottom` keep `carrot-up`/`carrot-down`.

### Controlled State

Control the drawer state externally:

```tsx
import { useState } from 'react';

function ControlledDrawer() {
  const [isOpen, setIsOpen] = useState(false);

  const drawer = useDrawer({
    open: isOpen,
    onOpenChange: setIsOpen,
  });

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open Drawer</Button>

      <Drawer.Root store={drawer}>
        <Drawer.Portal>
          <Drawer.Overlay>
            <Drawer.Content>
              <Button onClick={() => setIsOpen(false)}>Close Drawer</Button>
            </Drawer.Content>
          </Drawer.Overlay>
        </Drawer.Portal>
      </Drawer.Root>
    </>
  );
}
```

### Default Open State

Set the drawer to be open by default:

```tsx
const drawer = useDrawer({
  defaultOpen: true,
  title: 'Initially Open Drawer',
});
```

### Dismissible Behavior

Control whether the drawer can be dismissed by clicking outside or pressing Escape:

```tsx
const drawer = useDrawer({
  dismissable: true, // Can be closed by clicking overlay or pressing Escape
});
```

### Animation Duration

Customize the slide-in/out animation duration:

```tsx
const drawer = useDrawer({
  duration: 300, // Animation duration in milliseconds
});
```

### Manual Toggle Control

Programmatically control the drawer state:

```tsx
const drawer = useDrawer();

// Toggle between open/closed
const handleToggle = () => drawer.toggle();

// Force open
const handleOpen = () => drawer.toggle(true);

// Force close
const handleClose = () => drawer.toggle(false);
```

### Within a Container

Leaving out `Drawer.Portal` keeps the drawer in the DOM where you wrote it, so
it anchors to its container instead of the viewport. The container needs
`position: relative` and a height of its own:

```tsx
<div
  style={{
    position: 'relative',
    overflow: 'hidden',
    height: '360px',
    border: '1px solid #ddd',
    borderRadius: '8px',
  }}>
  <div>Main content</div>

  <Drawer.Root store={drawer}>
    <Drawer.Overlay>
      <Drawer.Content>Drawer content</Drawer.Content>
    </Drawer.Overlay>
  </Drawer.Root>
</div>
```

### Event Handling

Handle drawer state changes:

```tsx
const drawer = useDrawer({
  onOpenChange: (open, event, reason) => {
    console.log('Drawer state changed:', open);
    console.log('Reason:', reason); // 'click', 'escape-key', 'outside-press', etc.
  },
});
```

### Custom Styling

Apply custom styles to drawer components:

```tsx
<Drawer.Content
  css={{
    padding: '24px',
    maxWidth: '500px',
    backgroundColor: '#f8f9fa',
    borderRadius: '8px 0 0 8px',
    boxShadow: '0 4px 20px rgba(0,0,0,0.15)',
  }}>
  Custom styled content
</Drawer.Content>
```
