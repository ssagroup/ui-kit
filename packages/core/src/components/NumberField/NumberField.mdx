# NumberField

A labelled numeric input that formats the value while the user types and
reports a plain `number`. For free text use `TextField`; for a stepper with
plus and minus buttons use `Counter`.

## Default Usage

<Description of={NumberFieldStories.Default} />

```tsx
import { NumberField } from '@ssa-ui-kit/core';

const Amount = () => (
  <NumberField
    name="amount"
    id="formElement-amount"
    label="Amount"
    placeholder="Enter a number"
    defaultValue={1500}
    numberFormat={{ maximumIntegerDigits: 5, maximumFractionDigits: 2 }}
    onChange={(value) => console.log(value)}
  />
);
```

## Controlled

<Description of={NumberFieldStories.Controlled} />

```tsx
import { useState } from 'react';
import { NumberField } from '@ssa-ui-kit/core';

const Budget = () => {
  const [budget, setBudget] = useState(9999);
  return (
    <NumberField
      name="budget"
      id="formElement-budget"
      label="Budget"
      numberFormat={{ maximumFractionDigits: 0 }}
      value={budget}
      onChange={setBudget}
    />
  );
};
```

## React Hook Form

<Description of={NumberFieldStories.WithReactHookForm} />

```tsx
import { NumberField } from '@ssa-ui-kit/core';
import { Controller, useForm } from 'react-hook-form';

const Order = () => {
  const { control } = useForm({ defaultValues: { quantity: 0 } });
  return (
    <Controller
      name="quantity"
      control={control}
      rules={{ min: { value: 1, message: 'Order at least 1' } }}
      render={({ field, fieldState }) => (
        <NumberField
          name="quantity"
          id="formElement-quantity"
          label="Quantity"
          numberFormat={{ maximumFractionDigits: 0 }}
          value={field.value}
          onChange={field.onChange}
          status={fieldState.error ? 'error' : 'basic'}
          error={fieldState.error?.message}
        />
      )}
    />
  );
};
```

## Keyboard and Accessibility

NumberField is a native text `<input>` with `autoComplete="off"`. It takes
focus with Tab and has no arrow-key stepping; characters that don't fit the
format are dropped as you type.

- **Link the label.** The label's `htmlFor` is `id`, but the `<input>` id is
  always `formElement-{name}`. Pass `id="formElement-{name}"` so clicking
  the label focuses the field and screen readers announce it.
- Keep a visible `label`. Passing `inputProps` (for an `aria-label`, say)
  replaces NumberField's own `value` and `onChange`, and the field stops
  working.
- `status="error"` styles the field and shows `error`; it does not set
  `aria-invalid` or link the message with `aria-describedby`.
