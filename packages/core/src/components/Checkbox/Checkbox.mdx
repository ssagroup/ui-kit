# Checkbox

A native checkbox with a clickable label, in `primary` or `success` colours.
Use it for independent on/off options and multi-select lists; for a single
setting that applies immediately use `Switch`, and for one choice out of a set
use `RadioGroup`. Inside a react-hook-form form use `FormCheckbox`.

## Default Usage

<Description of={CheckboxStories.Default} />

```tsx
import { Checkbox } from '@ssa-ui-kit/core';

const Terms = () => (
  <Checkbox
    id="accept-terms"
    text="Accept terms and conditions"
    onChange={(checked) => console.log(checked)}
  />
);
```

## Controlled

<Description of={CheckboxStories.Controlled} />

```tsx
import { useState } from 'react';
import { Checkbox } from '@ssa-ui-kit/core';

const WeeklySummary = () => {
  const [checked, setChecked] = useState(false);
  return (
    <Checkbox
      text="Email me a weekly summary"
      checked={checked}
      onChange={setChecked}
    />
  );
};
```

## With react-hook-form

`FormCheckbox` takes the same props plus `name` and `control`, and writes the
boolean into the form on every toggle. It does not read the form value back,
so set `defaultChecked` to match `defaultValues` — `reset()` and `setValue()`
do not update the box.

```tsx
import { useForm } from 'react-hook-form';
import { Button, FormCheckbox } from '@ssa-ui-kit/core';

type Values = { newsletter: boolean };

const Newsletter = () => {
  const { control, handleSubmit } = useForm<Values>({
    defaultValues: { newsletter: true },
  });
  return (
    <form onSubmit={handleSubmit((values) => console.log(values))}>
      <FormCheckbox
        name="newsletter"
        control={control}
        text="Subscribe to newsletter"
        defaultChecked
      />
      <Button type="submit" text="Save" />
    </form>
  );
};
```

## Keyboard and Accessibility

Checkbox is a native `<input type="checkbox">` wrapped in a `<label>`: Tab
focuses it and Space toggles it.

- **`text` is the accessible name.** Without `text` the input has no name —
  only drop it when a visible label elsewhere is linked with
  `<label htmlFor={id}>`.
- `ref` points at the input. Other props (`className`, `css`, `aria-*`) land on
  the outer `<label>`, not on the input.
- `isIndeterminate` also sets the input's `indeterminate` property, so screen
  readers announce "mixed".
- `disabled` removes the input from the tab order.
