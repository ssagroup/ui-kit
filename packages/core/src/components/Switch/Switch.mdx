# Switch

## Default Usage

The Switch component provides a toggle control that allows users to switch between two states (on/off, enabled/disabled). It's commonly used for settings, preferences, and feature toggles with clear visual feedback:

```tsx
import { Switch, SwitchContextProvider } from '@ssa-ui-kit/core';

function BasicSwitch() {
  return (
    <SwitchContextProvider initialState={false}>
      <Switch label="Enable notifications" />
    </SwitchContextProvider>
  );
}
```

## Features

### Color Variants

The `color` prop controls the on-state background, hover color, and the
off-state focus outline. Colors are sourced from `theme.palette`.

| Value | Palette key | On background | On hover | Off outline |
|-------|-------------|---------------|----------|-------------|
| `primary` *(default)* | `palette.primary` | `primary.main` | `primary.dark` | `primary.light` |
| `success` | `palette.success` | `success.main` | `success.dark` | `success.light` |
| `custom` | — | via `colors.on` | `rgba(0,0,0,0.15)` overlay | via `colors.offOutline` |

The off state always shows a neutral grey background (`greyFocused`) regardless
of color variant. When disabled, the off state uses `greySelectedMenuItem`, while
the on state keeps its color — see [Disabled State](#disabled-state).

```tsx
// Default — primary (blue)
<SwitchContextProvider initialState={false}>
  <Switch label="Enable feature" />
</SwitchContextProvider>

// Success (green)
<SwitchContextProvider initialState={false}>
  <Switch label="Enable feature" color="success" />
</SwitchContextProvider>

// Custom escape hatch
<SwitchContextProvider initialState={false}>
  <Switch
    label="Custom toggle"
    color="custom"
    colors={{ on: '#ff0000', offOutline: '#ff9999' }}
  />
</SwitchContextProvider>
```

### Disabled State

Disabled switches cannot be toggled, and the two positions stay visually
distinct:

- **Disabled + on** keeps the variant's on-color, muted by a white overlay, so a
  locked-on setting still reads as on. This works the same for `primary`,
  `success`, and `custom` — a custom `colors.on` is dimmed by the same overlay,
  with no extra prop to set.
- **Disabled + off** uses a solid `greySelectedMenuItem` background.

The knob stays fully opaque in both cases, so its position remains a reliable
state cue.

```tsx
// Muted blue — still reads as "on"
<SwitchContextProvider initialState={true}>
  <Switch label="Locked feature" disabled />
</SwitchContextProvider>

// Solid grey
<SwitchContextProvider initialState={false}>
  <Switch label="Unavailable feature" disabled />
</SwitchContextProvider>
```

### Basic Toggle Functionality

Simple on/off switch with context provider:

```tsx
import { useState } from 'react';

function BasicToggleExample() {
  const [isEnabled, setIsEnabled] = useState(false);

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '16px' }}>
      <SwitchContextProvider initialState={isEnabled}>
        <div style={{ display: 'flex', alignItems: 'center', gap: '12px' }}>
          <Switch label="Dark mode" />
          <span>Dark mode</span>
        </div>
      </SwitchContextProvider>
      <SwitchContextProvider initialState={true}>
        <div style={{ display: 'flex', alignItems: 'center', gap: '12px' }}>
          <Switch label="Auto-save" />
          <span>Auto-save enabled</span>
        </div>
      </SwitchContextProvider>
    </div>
  );
}
```
