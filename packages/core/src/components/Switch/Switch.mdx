# Switch

An on/off toggle for a setting that takes effect immediately. For a choice
that is only applied on submit, or one of several independent options, use
`Checkbox`.

## Default Usage

<Description of={SwitchStories.Default} />

```tsx
import { Switch } from '@ssa-ui-kit/core';

const Notifications = () => (
  <Switch
    label="Email notifications"
    defaultChecked
    onChange={(checked) => console.log(checked)}
  />
);
```

## Controlled

<Description of={SwitchStories.Controlled} />

```tsx
import { useState } from 'react';
import { Switch } from '@ssa-ui-kit/core';

const DarkMode = () => {
  const [isOn, setIsOn] = useState(true);
  return <Switch label="Dark mode" checked={isOn} onChange={setIsOn} />;
};
```

## SwitchContextProvider

The original API, still supported. The provider holds the state; a Switch
inside it without `checked` or `defaultChecked` reads it, and `onChange`
still fires. Other children can read the state with `useSwitchContext()`.
Every Switch inside one provider shares the same state.

```tsx
import {
  Switch,
  SwitchContextProvider,
  Typography,
  useSwitchContext,
} from '@ssa-ui-kit/core';

const Status = () => {
  const { isOn } = useSwitchContext();
  return <Typography variant="body1">{isOn ? 'On' : 'Off'}</Typography>;
};

const WithProvider = () => (
  <SwitchContextProvider initialState={false}>
    <Switch label="Email notifications" />
    <Status />
  </SwitchContextProvider>
);
```

A Switch with no provider and none of `checked`, `defaultChecked` or
`onChange` stays off and ignores clicks.

## Keyboard and Accessibility

Switch is a `<button role="switch">` with `aria-checked`: Tab focuses it,
Space or Enter toggles it.

- **`label` is the accessible name** (`aria-label`) and is not rendered.
  Show a visible label next to it and keep the two in sync.
- `disabled` removes it from the tab order; a disabled switch also gets
  `aria-readonly`.
- The focus outline only appears while the switch is off.
