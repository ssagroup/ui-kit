# SearchBox

A compact, fixed-width search field that reports the term through a debounced
`callback`. For a full-width labelled text field use `TextField`; to search
inside a list of options use `Typeahead`.

## Default Usage

<Description of={SearchBoxStories.Default} />

```tsx
import { SearchBox } from '@ssa-ui-kit/core';
import { useForm } from 'react-hook-form';

const ProductSearch = ({ onSearch }: { onSearch: (term: string) => void }) => {
  const { register, control, resetField } = useForm();
  return (
    <SearchBox
      name="search"
      placeholder="Search products"
      register={register}
      control={control}
      resetField={resetField}
      callback={onSearch}
      inputProps={{ 'aria-label': 'Search products' }}
    />
  );
};
```

## Keyboard and Accessibility

| Key   | Action                                                    |
| ----- | --------------------------------------------------------- |
| Enter | Calls `callback` with the current term, skipping the wait |
| Tab   | Moves to the clear button when the field has text         |

- **Name the field.** SearchBox renders no label, so pass
  `inputProps={{ 'aria-label': '...' }}`. The placeholder is not a label.
- The clear button is a real `<button>` and is reachable by keyboard, but it
  has no accessible name yet; screen readers announce it as "button".
- Passing your own `onKeyUp` replaces the Enter handler, so Enter stops
  searching.
