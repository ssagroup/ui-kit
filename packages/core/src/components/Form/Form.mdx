# Form

A styled `<form>` that lays its children out as a wrapping flex row, with two
helpers: `FormGroup` for a full-width row and `FormAction` for the buttons.
It holds no state — use react-hook-form for values, validation and submit. For
a form generated from a JSON schema use `JsonSchemaForm`.

## Default Usage

<Description of={FormStories.Default} />

```tsx
import { useForm, FieldError } from 'react-hook-form';
import {
  Button,
  Form,
  FormAction,
  FormGroup,
  TextField,
} from '@ssa-ui-kit/core';

const SignIn = () => {
  const {
    register,
    handleSubmit,
    formState: { errors },
  } = useForm();
  return (
    <Form noValidate onSubmit={handleSubmit((values) => console.log(values))}>
      <FormGroup>
        <TextField
          name="email"
          label="Email"
          register={register}
          validationSchema={{ required: 'Enter your email' }}
          errors={errors.email as FieldError}
        />
      </FormGroup>
      <FormAction>
        <Button variant="primary" type="submit" text="Sign in" block />
      </FormAction>
    </Form>
  );
};
```

## Parts

| Part         | Element  | Layout                                                                      |
| ------------ | -------- | --------------------------------------------------------------------------- |
| `Form`       | `<form>` | `display: flex; flex-flow: row wrap`                                        |
| `FormGroup`  | `<div>`  | full-width row (`flex: 1 1 100%`), wraps its children, 10px vertical margin |
| `FormAction` | `<div>`  | full-width row (`flex: 1 1 100%`), no other styles                          |

All three accept every native attribute of their element plus `css` and
`className`.

## Notes

- `useForm()` is used untyped: TextField's `register` and `errors` expect the
  untyped form, so cast field errors with `as FieldError`.
- `validationSchema` rules run in react-hook-form only. Kit props named
  `isRequired` (Checkbox, RadioGroup, FormRadioGroup) also set the native
  `required` attribute — add `noValidate` to the form so the browser does not
  block the submit before react-hook-form shows its messages.
- Buttons default to `type="button"`. Set `type="submit"` on the submit
  button.
