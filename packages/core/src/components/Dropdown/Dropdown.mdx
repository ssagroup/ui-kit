# Dropdown

## Default Usage

The Dropdown component provides a select interface that allows users to choose one option from a list. It consists of a toggle button and a list of selectable options:

```tsx
import { Dropdown, DropdownOption } from '@ssa-ui-kit/core';

function BasicDropdown() {
  const items = [
    { id: 1, value: 'Option One', subText: 'Description 1' },
    { id: 2, value: 'Option Two', subText: 'Description 2' },
    { id: 3, value: 'Option Three', subText: 'Description 3' },
  ];

  const handleChange = (selectedItem) => {
    console.log('Selected:', selectedItem);
  };

  return (
    <Dropdown
      selectedItem={items[0]}
      onChange={handleChange}
      placeholder="Select an option">
      {items.map((item) => (
        <DropdownOption key={item.id} value={item.id}>
          {item.value}
        </DropdownOption>
      ))}
    </Dropdown>
  );
}
```

## Features

### Component-Specific Props

You can pass props to different parts of the Dropdown component using the `dropdownProps` object:

- `dropdownProps.base` - Props for the wrapper div element
- `dropdownProps.toggleButton` - Props for the button element (e.g., `name`, `id`, `data-*` attributes)
- `dropdownProps.toggleButtonArrow` - Props for the arrow icon SVG element
- `dropdownProps.dropdownPosition` - Controls the opening direction of the options list (`'auto'` | `'top'` | `'bottom'`)

```tsx
<Dropdown
  dropdownProps={{
    base: {
      id: 'my-dropdown-base',
    },
    toggleButton: {
      name: 'my-toggle',
    },
    toggleButtonArrow: {
      'data-custom-attribute': 'my-attribute'
    },
  }}
  selectedItem={items[0]}
  onChange={handleChange}
  placeholder="Select an option">
  {items.map((item) => (
    <DropdownOption key={item.id} value={item.id}>
      {item.value}
    </DropdownOption>
  ))}
</Dropdown>
```

### Width

By default the Dropdown sizes itself to its content. Use the `width` prop to give it an explicit
width — a number is treated as pixels, a string is used as-is, so `width="100%"` makes it fill
whatever container it is in:

```tsx
// Fill the surrounding form column
<Dropdown width="100%" selectedItem={items[0]} onChange={handleChange}>
  {items.map((item) => (
    <DropdownOption key={item.id} value={item.id}>
      {item.value}
    </DropdownOption>
  ))}
</Dropdown>

// Fixed width
<Dropdown width={320} selectedItem={items[0]} onChange={handleChange}>
  ...
</Dropdown>
```

This has to be a prop rather than a style override. The control is three nested elements deep — the
field wrapper, the positioning base, and the toggle button — and each of them sizes itself to its
content. `className` and `css` land on the toggle button only, so a `width: 100%` there resolves
against a base that is still shrink-wrapped and nothing moves.

The prop sizes all three, but only the outer wrapper receives the value — the base and the toggle
are set to `100%` so they fill it. That is what makes relative units behave: `width="60%"` is 60% of
the surrounding container. Repeating `60%` at each level would instead give 60% of 60% of 60%, i.e.
about 21% of the container.

The prop has no default, so existing dropdowns keep their content-based width. `dropdownProps.base`
continues to work: it is spread onto the base element as before, and an inline `style` there still
beats `width`, so a call site can be migrated gradually. `dropdownProps.toggleButton.css` also still
wins over `width` — it is merged last.

### Long Content

The selected value and the option labels are kept on a single line and ellipsised when they do not
fit. This is not configurable — the toggle button is a fixed 44px, so a wrapping label spills above
and below its border rather than being clipped.

Nothing grows past its container either: the field wrapper, the base and the toggle button are each
capped at `100%`, and the options list is capped at the width of the toggle. Previously the list was
sized to `max-content`, which let a single long option stretch it far past the viewport.

The practical consequence is that an option longer than the toggle is truncated rather than widening
the list. Give the dropdown an explicit `width` when the options need more room than the selected
value does.

Every option row carries a tooltip with its full label, so truncated text stays reachable. It opens
after a 1s hover — long enough not to fire while the pointer travels down the list — and is capped at
320px so it wraps instead of becoming as wide as the popup it explains. It sits above the row,
flipping below when there is no room — sideways placement is unstable, since a dropdown near the
right edge flips it left and a full-width one gets it clamped back over the list. The tooltip is
attached to all rows rather than only the truncated ones. The selected value in the toggle button
does not have one.

### Viewport-Aware Placement

By default (`dropdownPosition: 'auto'`) the options list opens downward. On every open the component
measures available space below the toggle button and automatically flips the list upward when there
is not enough room, preventing it from being clipped by the viewport edge.

Use `'top'` or `'bottom'` to force a fixed direction regardless of available space.

```tsx
{/* Always opens upward — useful when the dropdown is near the bottom of the page */}
<Dropdown
  selectedItem={items[0]}
  onChange={handleChange}
  dropdownProps={{ dropdownPosition: 'top' }}>
  {items.map((item) => (
    <DropdownOption key={item.id} value={item.id}>
      {item.value}
    </DropdownOption>
  ))}
</Dropdown>

{/* Automatic flip based on available viewport space (default) */}
<Dropdown
  selectedItem={items[0]}
  onChange={handleChange}
  dropdownProps={{ dropdownPosition: 'auto' }}>
  {items.map((item) => (
    <DropdownOption key={item.id} value={item.id}>
      {item.value}
    </DropdownOption>
  ))}
</Dropdown>
```


### Simple Value Options

Use simple string or number values for basic dropdowns:

```tsx
const simpleItems = ['Apple', 'Banana', 'Cherry', 'Date'];

<Dropdown placeholder="Select a fruit">
  {simpleItems.map((item) => (
    <DropdownOption key={item} value={item} />
  ))}
</Dropdown>;
```

### Pre-selected Items

Set an initial selected item:

```tsx
<Dropdown selectedItem={items[2]} onChange={handleChange}>
  {items.map((item) => (
    <DropdownOption key={item.id} value={item.id}>
      {item.value}
    </DropdownOption>
  ))}
</Dropdown>
```

### Disabled State

Disable the entire dropdown when needed:

```tsx
<Dropdown selectedItem={items[0]} disabled={true} onChange={handleChange}>
  {items.map((item) => (
    <DropdownOption key={item.id} value={item.id}>
      {item.value}
    </DropdownOption>
  ))}
</Dropdown>
```

### Controlled Open State

Control whether the dropdown is open programmatically:

```tsx
import { useState } from 'react';

function ControlledDropdown() {
  const [isOpen, setIsOpen] = useState(true);

  return (
    <Dropdown isOpen={isOpen} onChange={handleChange}>
      {items.map((item) => (
        <DropdownOption key={item.id} value={item.id}>
          {item.value}
        </DropdownOption>
      ))}
    </Dropdown>
  );
}
```

### Dynamic Selection Updates

Update the selected item externally:

```tsx
import { useState } from 'react';

function DynamicDropdown() {
  const [selectedIndex, setSelectedIndex] = useState(0);

  const handleUpdate = () => {
    const newIndex = selectedIndex < items.length - 1 ? selectedIndex + 1 : 0;
    setSelectedIndex(newIndex);
  };

  return (
    <div>
      <Dropdown selectedItem={items[selectedIndex]} onChange={handleChange}>
        {items.map((item) => (
          <DropdownOption key={item.id} value={item.value} />
        ))}
      </Dropdown>
      <Button onClick={handleUpdate}>Update Selection</Button>
    </div>
  );
}
```

### Custom Option Content

Create rich option content with custom elements:

```tsx
<Dropdown selectedItem={items[0]} onChange={handleChange}>
  {items.map((item) => (
    <DropdownOption key={item.id} value={item.id} label={item.value}>
      <div>
        <strong>{item.value}</strong>
        <span style={{ color: '#666' }}> | {item.subText}</span>
      </div>
    </DropdownOption>
  ))}
</Dropdown>
```

### Empty State

Handle dropdowns with no options:

```tsx
<Dropdown placeholder="No options available">{null}</Dropdown>
```

### Custom Styling

Apply custom styles to the dropdown and options:

```tsx
import styled from '@emotion/styled';
import { css } from '@emotion/react';

const CustomOption = styled(DropdownOption)`
  padding: 12px 16px;
  background: #f8f9fa;
  border-bottom: 1px solid #dee2e6;

  &:hover {
    background: #e9ecef;
  }
`;

<Dropdown
  selectedItem={items[0]}
  onChange={handleChange}
  css={css`
    background: #fff;
    border: 2px solid #007bff;
    border-radius: 8px;

    &:focus {
      border-color: #0056b3;
      box-shadow: 0 0 0 3px rgba(0, 123, 255, 0.25);
    }

    &[aria-expanded='true'] {
      border-color: #0056b3;
    }
  `}>
  {items.map((item) => (
    <CustomOption key={item.id} value={item.id}>
      {item.value}
    </CustomOption>
  ))}
</Dropdown>;
```

### Placeholder Text

Customize the placeholder when no item is selected:

```tsx
<Dropdown placeholder="Choose your preferred option..." onChange={handleChange}>
  {items.map((item) => (
    <DropdownOption key={item.id} value={item.id}>
      {item.value}
    </DropdownOption>
  ))}
</Dropdown>
```

### Option Labels

Use different display text vs values:

```tsx
<Dropdown onChange={handleChange}>
  {items.map((item) => (
    <DropdownOption key={item.id} value={item.id} label={item.value}>
      {item.value} - {item.subText}
    </DropdownOption>
  ))}
</Dropdown>
```
