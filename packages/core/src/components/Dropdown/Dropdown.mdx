# Dropdown

A select-only control for choosing one option from a list: a toggle button
that shows the current selection, and a list of `DropdownOption`s that opens
below (or above) it. For several selections use `MultipleDropdown`; for a
searchable list use `Typeahead`.

## Default Usage

<Description of={DropdownStories.Default} />

```tsx
import { Dropdown, DropdownOption } from '@ssa-ui-kit/core';

const items = [
  { value: 1, label: 'Design' },
  { value: 2, label: 'Engineering' },
  { value: 3, label: 'Finance' },
];

<Dropdown
  selectedItem={items[0]}
  onChange={(item) => console.log(item.value)}
  placeholder="Select a department">
  {items.map((item) => (
    <DropdownOption key={item.value} value={item.value} label={item.label} />
  ))}
</Dropdown>;
```

## Groups

<Description of={DropdownStories.Groups} />

```tsx
import { useState } from 'react';
import {
  Dropdown,
  DropdownOption,
  DropdownOptionGroup,
  type DropdownOptionProps,
} from '@ssa-ui-kit/core';

const [selected, setSelected] = useState<DropdownOptionProps>({
  value: 'banana',
  label: 'Banana',
});

<Dropdown selectedItem={selected} onChange={setSelected}>
  <DropdownOptionGroup label="Fruits">
    <DropdownOption value="apple" label="Apple" />
    <DropdownOption value="banana" label="Banana" />
  </DropdownOptionGroup>
  <DropdownOptionGroup label="Vegetables">
    <DropdownOption value="carrot" label="Carrot" />
  </DropdownOptionGroup>
</Dropdown>;
```

## Sub-component Props

`dropdownProps` passes props to the inner parts:

- `base` — the positioning wrapper `div`
- `toggleButton` — the toggle `button` (e.g. `name`, `id`, `data-*`). Props
  the dropdown manages itself (`onClick`, `role`, `aria-expanded`, …) are not
  accepted.
- `toggleButtonArrow` — the arrow icon
- `dropdownPosition` — see [Placement](#placement)

## Keyboard and Accessibility

The toggle is a select-only `combobox` that keeps focus while the list is open;
the highlighted option is announced through `aria-activedescendant`.

| Key                     | Action                                     |
| ----------------------- | ------------------------------------------ |
| `ArrowDown` / `ArrowUp` | Open the list; move the highlight          |
| `Home` / `End`          | Highlight the first / last option          |
| `Enter` / `Space`       | Open the list; pick the highlighted option |
| `Escape`                | Close the list                             |
| `Tab`                   | Close the list and move focus on           |

`label` is wired to the toggle through `aria-labelledby`. Without a visible
label, pass `dropdownProps.toggleButton['aria-label']`.
