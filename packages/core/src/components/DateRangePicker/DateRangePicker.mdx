# DateRangePicker

Two masked fields (**from** → **to**) with one **popover calendar**, **Luxon** parsing, and **react-hook-form** fields derived from **`name`** (e.g. **`nameFrom`** / **`nameTo`**). **`onChange`** returns a tuple of **`Date`**, **`undefined`**, or **`null`** on the **end** only for **Present** (ongoing range). Use **`DateRangePickerFormBridge`** when forms store **ISO** strings and the **`Present`** sentinel. **`rangePickerType`** selects day / month / year density; **`showPresentOption`** adds an end-only **Present** action.

## Default Usage

The DateRangePicker component allows users to select a range of dates using two connected input fields with masked entry and a shared calendar popup. Here's how to use it:

```tsx
import { DateRangePicker } from '@ssa-ui-kit/core';

function BasicDateRangePicker() {
  const handleDateRangeChange = (dates?: [Date | null, Date | null]) => {
    console.log('Selected range:', dates);
    if (dates && dates[0] && dates[1]) {
      console.log('From:', dates[0]);
      console.log('To:', dates[1]);
    }
  };

  return (
    <DateRangePicker
      name="dateRange"
      label="Date Range"
      messages={{
        description: 'Select your preferred date range',
      }}
      onChange={handleDateRangeChange}
    />
  );
}
```

## Features

### Date Formats

Support for different date formats with automatic input masking for both fields:

```tsx
// US format (default)
<DateRangePicker
  name="range-us"
  label="US Format Range"
  format="mm/dd/yyyy"
  onChange={handleDateRangeChange}
/>

// European format
<DateRangePicker
  name="range-eu"
  label="European Format Range"
  format="dd/mm/yyyy"
  onChange={handleDateRangeChange}
/>
```

### Calendar Opening Modes

Control how users can access the calendar popup:

```tsx
// Icon only
<DateRangePicker
  name="range-icon"
  label="Icon Only"
  openCalendarMode="icon"
  onChange={handleDateRangeChange}
/>

// Input field clicks
<DateRangePicker
  name="range-input"
  label="Input Click"
  openCalendarMode="input"
  onChange={handleDateRangeChange}
/>

// Both icon and inputs (default)
<DateRangePicker
  name="range-both"
  label="Icon and Inputs"
  openCalendarMode="both"
  onChange={handleDateRangeChange}
/>
```

### Date Range Restrictions

Set minimum and maximum date boundaries for the entire range:

```tsx
<DateRangePicker
  name="restricted-range"
  label="Restricted Range"
  dateMin="01/01/2024"
  dateMax="12/31/2025"
  onChange={handleDateRangeChange}
/>
```

### Default Values

Set initial date ranges for the picker:

```tsx
<DateRangePicker
  name="preset-range"
  label="With Default Range"
  defaultValue={['02/10/2025', '02/15/2025']}
  onChange={handleDateRangeChange}
/>
```

### External Value Control

Control the date range externally for programmatic updates:

```tsx
import { useState, useEffect } from 'react';

function ControlledDateRangePicker() {
  const [selectedRange, setSelectedRange] = useState<[string, string]>([
    '01/15/2025',
    '01/25/2025',
  ]);

  useEffect(() => {
    // Programmatically update range
    const timer = setTimeout(() => {
      setSelectedRange(['02/10/2025', '02/28/2025']);
    }, 3000);
    return () => clearTimeout(timer);
  }, []);

  return (
    <DateRangePicker
      name="controlled-range"
      label="Controlled Range"
      value={selectedRange}
      onChange={(dates) => {
        if (dates && dates[0] && dates[1]) {
          setSelectedRange([
            dates[0].toLocaleDateString('en-US'),
            dates[1].toLocaleDateString('en-US'),
          ]);
        }
      }}
    />
  );
}
```

### Status States

Display different validation states with custom messages:

```tsx
// Success state
<DateRangePicker
  name="success-range"
  label="Valid Range"
  status="success"
  messages={{
    success: 'Date range is valid!'
  }}
  onChange={handleDateRangeChange}
/>

// Error state
<DateRangePicker
  name="error-range"
  label="Invalid Range"
  status="error"
  messages={{
    error: 'Please select a valid date range'
  }}
  onChange={handleDateRangeChange}
/>
```

### Clear Button

Set **`showClearButton`** to add a **×** beside the calendar icon. A single button resets the
**whole range**: it appears only while either field differs from **`defaultValue`**, restores
that default when clicked, and rewinds range selection so the next click starts a fresh
range. With no **`defaultValue`** it empties both fields:

```tsx
<DateRangePicker
  name="period"
  label="Reporting period"
  showClearButton
  defaultValue={['02/10/2025', '02/15/2025']}
/>
```

### Presets

Pass **`presets`** to list shortcut ranges to the left of the calendar. Clicking one applies
the range and **keeps the popover open**, so the user can still fine-tune the dates by hand;
the matching item stays highlighted while the range is unchanged. Nothing renders when the
prop is omitted or empty, so the popover keeps its original width.

Use the ready-made set:

```tsx
import { DateRangePicker, DEFAULT_DATE_RANGE_PRESETS } from '@ssa-ui-kit/core';

<DateRangePicker
  name="report"
  label="Reporting period"
  presets={DEFAULT_DATE_RANGE_PRESETS}
  onChange={handleDateRangeChange}
/>;
```

**`DEFAULT_DATE_RANGE_PRESETS`** contains **Today**, **Yesterday**, **Current week**,
**Last week**, **Current month**, and **Last month**. Each one is also exported on its own
(**`todayPreset`**, **`yesterdayPreset`**, **`currentWeekPreset`**, **`lastWeekPreset`**,
**`currentMonthPreset`**, **`lastMonthPreset`**) so the set and its order can be composed:

```tsx
import {
  DateRangePicker,
  todayPreset,
  currentMonthPreset,
  type DateRangePreset,
} from '@ssa-ui-kit/core';

const lastSevenDays: DateRangePreset = {
  label: 'Last 7 days',
  // A function is resolved at click time, so a relative range can never go
  // stale in an app that stays open across midnight.
  dateRange: () => {
    const to = new Date();
    const from = new Date(to);
    from.setDate(from.getDate() - 6);
    return [from, to];
  },
};

const fixedQuarter: DateRangePreset = {
  label: 'Q1 2025',
  // A fixed range can be a plain tuple.
  dateRange: [new Date(2025, 0, 1), new Date(2025, 2, 31)],
};

<DateRangePicker
  name="report"
  presets={[todayPreset, lastSevenDays, currentMonthPreset, fixedQuarter]}
/>;
```

Every entry follows the same shape — a **`label`** and a **`dateRange`**. A reversed tuple is
swapped, ends outside **`dateMin`** / **`dateMax`** are clamped to those bounds, and a range
lying entirely outside them is ignored. After a preset is applied, the next click in the
calendar starts a **new** range rather than moving the end date.

Style the column through **`classNames.presets`**:

```tsx
<DateRangePicker
  name="report"
  presets={DEFAULT_DATE_RANGE_PRESETS}
  classNames={{ presets: { root: 'custom-presets', item: 'custom-preset' } }}
/>
```

### Disabled State

Disable the date range picker when needed:

```tsx
<DateRangePicker
  name="disabled-range"
  label="Disabled Range Picker"
  disabled={true}
  defaultValue={['02/10/2025', '02/15/2025']}
  onChange={handleDateRangeChange}
/>
```

### Event Handling

Comprehensive event handling for different interactions:

```tsx
<DateRangePicker
  name="event-range"
  label="Event Handling"
  onChange={(dates) => console.log('Range changed:', dates)}
  onOpen={() => console.log('Calendar opened')}
  onClose={() => console.log('Calendar closed')}
  onError={(date, error) => console.log('Error:', error)}
  onMonthChange={(date) => console.log('Month changed:', date)}
  onYearChange={(date) => console.log('Year changed:', date)}
  onBlur={(event) => console.log('Input blurred')}
/>
```

Apply custom CSS classes to different parts of the component:

```tsx
<DateRangePicker
  name="styled-range"
  label="Custom Styled"
  onChange={handleDateRangeChange}
  classNames={{

      root: 'custom-trigger-root',

      inputFrom: 'custom-input-from',
      inputTo: 'custom-input-to',
      arrowIcon: 'custom-arrow',
      calendarIcon: 'custom-calendar-icon',
    },
    calendar: 'custom-calendar',
    label: 'custom-label',
    presets: {
      root: 'custom-presets',
      item: 'custom-preset',
    },
  }}
/>
```

### Monthly selection

Allows users to select a range of months:

```tsx
<DateRangePicker
  name="disabled-range"
  label="Disabled Range Picker"
  rangePickerType={'months'}
  defaultValue={['04/2025', '06/2025']}
  onChange={handleDateRangeChange}
/>
```
