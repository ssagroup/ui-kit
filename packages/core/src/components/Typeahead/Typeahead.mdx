# Typeahead

A searchable select: an input that filters a list of `TypeaheadOption`s as
the user types, for one value or (with `isMultiple`) several shown as chips.
It works on its own or as a react-hook-form field. For a short list with no
search use `Dropdown` or `MultipleDropdown`.

## Default Usage

<Description of={TypeaheadStories.Default} />

```tsx
import { Typeahead, TypeaheadOption } from '@ssa-ui-kit/core';

const items = [
  { value: 1, label: 'Design' },
  { value: 2, label: 'Engineering' },
  { value: 3, label: 'Finance' },
];

<Typeahead
  name="department"
  label="Department"
  defaultValue={[2]}
  onChange={(value, isSelected) => console.log(value, isSelected)}>
  {items.map((item) => (
    <TypeaheadOption key={item.value} value={item.value} label={item.label} />
  ))}
</Typeahead>;
```

  highlightInputMatch,

  name="department"

## Controlled Selection

<Description of={TypeaheadStories.Controlled} />

```tsx
import { useState } from 'react';
import {
  Typeahead,
  TypeaheadOption,
  type TypeaheadValue,
} from '@ssa-ui-kit/core';

// `items` as in Default Usage
const [selected, setSelected] = useState<TypeaheadValue[]>([2]);

<Typeahead
  name="departments"
  isMultiple
  value={selected}
  onChange={(value, isSelected) =>
    setSelected((prev) =>
      isSelected ? [...prev, value] : prev.filter((item) => item !== value),
    )
  }
  onClearAll={() => setSelected([])}>
  {items.map((item) => (
    <TypeaheadOption key={item.value} value={item.value} label={item.label} />
  ))}
</Typeahead>;
```

## React Hook Form

<Description of={TypeaheadStories.ReactHookForm} />

```tsx
import { FormProvider, useForm } from 'react-hook-form';
import { Typeahead, TypeaheadOption } from '@ssa-ui-kit/core';

// `items` as in Default Usage
const form = useForm({ defaultValues: { departments: [1, 2] } });

<FormProvider {...form}>
  <form onSubmit={form.handleSubmit((data) => console.log(data.departments))}>
    <Typeahead
      name="departments"
      label="Departments"
      isMultiple
      validationSchema={{ required: 'Pick at least one department' }}>
      {items.map((item) => (
        <TypeaheadOption
          key={item.value}
          value={item.value}
          label={item.label}
        />
      ))}
    </Typeahead>
  </form>
</FormProvider>;
```

## Styling

- `width` sizes the whole field (300px by default); a `css` width only sizes
  the trigger.
- `className` (and `css`) land on the trigger; `wrapperClassName`,
  `popoverClassName` and `optionsClassName` reach the field wrapper, the
  popover and the options list.
- `startIcon` / `endIcon` sit inside the trigger, with `startIconClassName` /
  `endIconClassName` for their wrappers.
- Options are read as data and never rendered as elements, so
  `styled(TypeaheadOption)` and a `css` prop on an option have no effect; use
  `children`, `avatar` or `renderOption`.

## Keyboard and Accessibility

The input is a `combobox` that keeps focus while the list is open; the
highlighted option is announced through `aria-activedescendant`.

| Key                     | Action                                                     |
| ----------------------- | ---------------------------------------------------------- |
| `ArrowDown` / `ArrowUp` | Open the list; move the highlight                          |
| `Enter`                 | Pick the highlighted option, or add the typed custom value |
| `Enter` / `Tab`         | Accept the inline suggestion for the first match           |
| `Backspace`             | In an empty input with `isMultiple`, remove the last chip  |
| `Escape`                | Close the list                                             |

`label` is wired to the input; without a visible label the combobox has no
accessible name, so always pass one.
