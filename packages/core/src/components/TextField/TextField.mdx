# TextField

A ready-made text field — label, control and helper row — for single-line
text (`Input`) or, with `multirow`, multi-line text (`Textarea`). Reach for it
first in forms. Use a bare `Input` when the label lives elsewhere, and compose
`Field` parts when you need a different layout or a non-text control.

## Default Usage

<Description of={TextFieldStories.Default} />

```tsx
import { TextField } from '@ssa-ui-kit/core';
import { useForm } from 'react-hook-form';

const UsernameField = () => {
  const { register } = useForm();
  return (
    <TextField
      name="username"
      label="Username"
      placeholder="Choose a username"
      helperText="Letters, numbers and dots only"
      register={register}
    />
  );
};
```

## React Hook Form

<Description of={TextFieldStories.ReactHookForm} />

```tsx
import { Button, TextField } from '@ssa-ui-kit/core';
import { FieldError, useForm } from 'react-hook-form';

const InviteForm = () => {
  const {
    register,
    handleSubmit,
    formState: { errors },
  } = useForm();

  return (
    <form onSubmit={handleSubmit((data) => console.log(data.email))}>
      <TextField
        name="email"
        label="Email"
        type="email"
        register={register}
        validationSchema={{ required: 'Email is required' }}
        errors={errors.email as FieldError}
        helperText="We'll send the invite here"
      />
      <Button type="submit" variant="primary" text="Send invite" />
    </form>
  );
};
```

## Keyboard and Accessibility

The control is a native `<input>` or `<textarea>`, with no keyboard handling of
its own.

- The `<label>` is linked to the control through `htmlFor="formElement-{name}"`.
  Without `label` an empty `<label>` still renders: name the field with
  `inputProps={{ 'aria-label': '…' }}` instead (single-line).
- `labelBadge` is linked as the control's `aria-describedby`, so it is read as
  a description rather than as part of the name.
- The helper row is `role="status"`, so its text is announced when it changes.
  It is not linked to the control with `aria-describedby`, and an error does
  not set `aria-invalid`.
